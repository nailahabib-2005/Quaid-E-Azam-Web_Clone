# Quaid-e-Azam Web Clone

A multi-page educational website clone created as a web development assignment. The project recreates a university-style website layout with multiple sections for academics, admissions, faculty, research, and other educational information.

## 🌐 Live Website

[View Live Website](https://nailahabib-2005.github.io/Quaid-E-Azam-Web_Clone/)

## 📌 Project Overview

This project focuses on creating a complete multi-page website using HTML and CSS.

The website is organized into different pages so users can easily navigate through academic information, admission details, faculty information, research, and other university-related sections.

The project also uses different images and web assets to make the pages more visually informative.

## ✨ Features

* Multi-page website
* Home page
* Academic information
* Admission information
* Faculty section
* Research section
* Funding section
* Educational content sections
* Image-based content
* Navigation between pages
* CSS-based website styling
* Organized page structure

## 📄 Main Pages

* `index.html` — Main/Home page
* `acadmic.html` — Academic information
* `admission.html` — Admission information
* `faculty.html` — Faculty information
* `funded.html` — Funding information
* `research.html` — Research information
